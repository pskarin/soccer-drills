# Skjutande stjärnan (Shooting Star)

## Syfte

En rolig skjutoövning som fokuserar på att ta emot en passning, vända och avsluta mot mål så snabbt som möjligt i ett trångt utrymme.

Det här är en av mitt U10-lags favoritövningar för skott. Den håller allas uppmärksamhet och ger alla chansen att få till många snabba avslut mot mål.

## Upplägg

Sätt upp ett "skjutfält" på 5 gånger 5 yards, markerat med koner, vid insidan av toppen av straffområdet. Forma sedan en "stjärna" av koner runt fältet i mitten genom att placera en kon cirka 3–4 yards in från varje hörnflagga, sedan en kon cirka 3–4 yards från varje övre hörn av straffområdet, och den sista konen cirka 10–15 yards ovanför skjutfältet i mitten. Se diagrammet nedan; med start från vänster hörn är stjärnkonerna numrerade 1–5.

Justera gärna avstånden från stjärnkonerna till skjutfältet efter din åldersgrupps behov.

Fördela fotbollar jämnt mellan de 5 stjärnkonerna. Du kan behöva eller vilja ha så många fotbollar som möjligt för att hålla speltempot uppe — vilket också hjälper konditionen. Assisterande tränare kan hjälpa dig att plocka bollar från missade skott.

```
-----------|'''|-----------
| 1 |                 | 5 |
|   |      .   .      |   |
|   |                 |   |
| 2  ------.---.------  4 |
|                         |
|                         |
|            3            |
|                         |
```

## Spelare

Du behöver minst 6 spelare och en målvakt. Fem av spelarna ställer upp vid var och en av de numrerade stjärnkonerna, och en utses till "anfallare" inne i skjutfältet.

Har du fler än 6 spelare och en målvakt, fördela spelarna så jämnt som möjligt i en kö bakom var och en av stjärnkonerna.

```
-----------|'''|-----------
| 1 |                 | 5 |
|   |      .   .      |   |
|   |                 |   |
| 2  ------.---.------  4 |
|                         |
|                         |
|            3            |
|                         |
```

## Så spelar man

Spelet börjar med en passning från spelaren vid kon 1 till anfallaren inne i skjutfältet. Anfallaren tar emot bollen, vrider och skjuter inifrån fältet så snabbt som möjligt. Därefter passar spelaren vid kon 2 till anfallaren, som tar emot, vrider och skjuter igen. Och så vidare genom kon nummer 5.

När anfallaren har skjutit 5 skott roterar spelarna moturs till nästa numrerade kon, och kon 5 går in i skjutfältet för att bli nästa anfallare.

Har du fler än 6 spelare roterar spelarna till baks till sina respektive köer.

Målet är att göra så många mål som möjligt i högt tempo. Snabb vändning. Snabbt skott. Snabb återhämtning för nästa passning.

## Längd

Du kan spela i 15 till 20 minuter, eller tills varje spelare har varit anfallare 2–3 gånger.

## Progressioner

- Istället för att anfallaren tar emot passningarna i ordning (1–5) kan tränaren ropa en siffra slumpmässigt. Det gör övningen mer dynamisk och rolig och utvecklar anfallarens situationsmedvetenhet/uppmärksamhet.

## Träningspoäng

- Gör först en frigöringsrörelse bort från ytan, för att skapa utrymme för mottagning och vändning
- Vänd snabbt med god kontroll
  - Vändning med insidan av foten
  - Vändning med utsidan av foten
- Förbered ditt skott
  - Se till att få bollen i en position för en stabil avslutning så snabbt som möjligt
- Följ upp returer!
- Snabb återhämtning när du lokaliserar nästa passning
- Kommunikation mellan anfallare och passare
